## 一、测试范围

- 数据层：baostock 回填、EOD 增量、日历补齐、校验、修复、指数/ETF 同步、宏观同步、财报同步、进度文件、爬虫锁。
- 因子层：表达式 AST 沙箱、因子评价、Alpha158 补算、IC 缓存键、因子校验器。
- 回测层：qlib/vbt 双引擎、组合报告、规则策略。
- 挖掘层：符号回归、AI 策略生成、AutoML bundle 重建。
- 系统层：鉴权、配置兼容、日志清理与检索、文档加载、WebSocket 管理、数据库集成。
- 前端：lint、SFC 解析检查、Vite build。

运行方式：
```bash
# 全量（需本地 PG）
DATABASE_URL=postgresql+asyncpg://quantlab:quantlab@localhost:5432/quantlab .venv/bin/python -m pytest
# 单文件 / 单用例
.venv/bin/python -m pytest backend/tests/test_alpha158.py
.venv/bin/python -m pytest backend/tests/test_alpha158.py::TestBackfillAlpha158Metrics::test_backfill_with_ids_no_match
```

说明：`conftest.py` 注入 fake qlib 模块，纯 mock 用例无需真实 qlib；DB 用例在无 `DATABASE_URL` 时自动 skip。

## 三、并发测试方案

- **DB 连接池**：因子批量补算 + 并发请求时，单 DB 写线程确保池不耗尽（asyncio.Queue 消费模型）。
- **爬虫串行**：baostock 任务由 `sync_lock` flock 串行化；并发触发仅首个执行。
- **回测/挖掘并发**：CPU 密集任务进进程池，验证事件循环不被阻塞（`/health` 保持秒级响应）。
- **日历伸缩阻断**：`calendar_shifting_active` 期间回测/挖掘接口应返回 409/等待，验证不产生半程数据。

## 五、测试数据准备

- **本地 PG**：`quantlab/quantlab@localhost:5432/quantlab`，表由 `init_db()`（create_all）建立。
- **mock qlib**：`conftest.py` 注入 fake qlib 模块，使无 qlib 环境的单元测试可运行。
- **bin 数据**：`data/qlib_bin/cn_data/` 已有真实回填数据，供集成/校验用例使用。
- **特殊数据**：构造停牌日、新 IPO（短区间）、退市股（超长区间）样本用于边界用例。
- **注意**：`test_macro_api.py::test_macro_upsert_idempotent` 写固定 `(PMI, 2026-07-01, pmi)` 行并断言 n1==1，二次运行需先删该行或 `--deselect`（flaky-by-design）。
