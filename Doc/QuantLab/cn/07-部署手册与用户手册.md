# 第一部分：部署手册

## 一、环境要求

### 1.1 运行环境

| 项目 | 要求 |
|------|------|
| 操作系统 | Linux（开发在 WSL 验证） |
| Python | 3.11（pyqlib 不支持 3.13，务必 pin） |
| Node.js | ≥ 18（Vite 构建） |
| PostgreSQL | 16（CI）/ 18（本地，quantlab/quantlab） |
| 磁盘 | qlib bin 约 6GB + PG 数据 + 备份（data/backup 571MB） |

### 1.2 依赖组件

| 组件 | 用途 |
|------|------|
| pyqlib | 因子计算与回测（重量级，需单独安装） |
| baostock / akshare | 行情与财报数据源 |
| asyncpg / psycopg | PG 驱动 |
| Alembic | 数据库迁移 |
| slowapi / apscheduler / fastapi-users / prometheus-client | 限流/调度/鉴权/指标 |
| Vue 3 / Element Plus / Pinia / vue-echarts | 前端 |

## 二、配置项说明

### 2.1 `.env`（必须，含密钥）

```
POSTGRES_USER=quantlab
POSTGRES_PASSWORD=quantlab
POSTGRES_DB=quantlab
POSTGRES_HOST=localhost
POSTGRES_PORT=5432
SECRET_KEY=<随机串>          # 生产必须改，否则启动阻断
ADMIN_PASSWORD=<强密码>
AUTH_ENABLED=false           # 生产建议 true
APP_ENV=development          # production 时关闭 /docs 且强制密钥
# AI Provider（任一即可，支持故障切换）
OPENCODEZEN_API_KEY=...
GLM_API_KEY=...
SILICONFLOW_API_KEY=...
```

### 2.2 `config.yaml`（运行时调优）

日志级别/目录、执行器线程/进程池大小、限流阈值、qlib provider 等。

## 三、部署步骤

### 3.1 环境引导

```bash
./setup.sh   # 创建 venv + 安装依赖 + 数据目录 + .env
```

### 3.2 启动开发服务

```bash
./start.sh dev    # 后端 :8000（--reload）+ 前端 :3000，日志 tee 到 logs/
```

或分开：
```bash
# 后端（cwd=backend）
.venv/bin/python -m uvicorn app.main:app --reload --host 0.0.0.0 --port 8000
# 前端
cd frontend && npm run dev
```

### 3.3 数据库初始化

```bash
cd backend
POSTGRES_USER=quantlab POSTGRES_PASSWORD=quantlab POSTGRES_DB=quantlab \
  ../.venv/bin/python -m alembic upgrade head
```
首次建库由应用 `init_db()` 执行 `create_all`，再 `alembic upgrade head`（基线迁移为空 upgrade）。

### 3.4 数据同步（手动）

```bash
# 一键全同步（A股回填→指数→宏观→财报→外盘）
curl -X POST 'http://localhost:8000/api/v1/quant/data/sync-full?years=5'
# 增量 EOD
curl -X POST 'http://localhost:8000/api/v1/quant/data/eod-sync?source=baostock&days=5'
# 数据校验 / 一键补齐
curl 'http://localhost:8000/api/v1/quant/data/validate?universe=all'
curl -X POST 'http://localhost:8000/api/v1/quant/data/repair' -H 'Content-Type: application/json' \
  -d '{"universe":"all","include_baostock":false}'
```

### 3.5 生产构建

```bash
cd frontend && npm run build    # dist/
# 挂载静态目录或设置 STATIC_DIR，SPA 兜底由后端处理
```

## 四、运维监控

- **健康检查**：`GET /health`（DB/qlib/调度器/磁盘/WS/AI），degraded 时逐项排查。
- **指标**：`GET /metrics`（Prometheus 抓取：请求量、执行器使用、慢查询）。
- **日志**：`logs/` 按大小轮转 + 每日清理；`GET /logs` 错误检索。
- **同步监控**：`GET /quant/data/sync-progress` + WebSocket 推送。
- **备份**：`pg_dump -Fc data/backup/`（恢复 `pg_restore --clean`）。

# 第二部分：用户手册

## 一、功能操作指南

### 1.1 研究首页（Dashboard）
- 展示数据新鲜度、最近回测/因子评价概览、健康状态。

### 1.2 因子库（FactorLibrary）
- 新增因子：弹窗/JSON 表单填表达式（qlib 语法），提交后经沙箱校验。
- 补算指标：工具栏「补算指标」批量评价选中因子（不仅限 alpha158）。
- AI 解释：对因子请求 AI 解读与追问，结果持久化。

### 1.3 策略回测（Strategy / StrategyLibrary）
- 建策略：选因子、组合方式、TopK、调仓频率、基准、正交化。
- 回测：选择区间与引擎（qlib/vbt），等待结果（进度实时推送）。
- 参数扫描 / Walk-Forward / 回测对比 / 组合报告 / AI 复盘。

### 1.4 AI 因子挖掘（Mining）
- 选引擎（LLM/符号回归/AutoML/文本）提交任务，查看候选与 best_ic。
- 模板一键运行；任务结果因子一键入库。

### 1.5 数据管理（DataStatus）
- 一键全同步 / 增量 EOD / 指数 / ETF / 财报 / 外盘按钮。
- 数据校验 + 一键补齐；同步统计面板；指数/ETF 注册表。
- 同步进度实时展示（WebSocket）。

### 1.6 宏观指标（Macro）
- 查看 PMI/CPI/PPI/GDP/SHIBOR 等图表；触发同步。

### 1.7 因子/回测对比、深度分析
- 多因子 IC 对比；多回测绩效对比；因子分域/分位/行业稳健性分析。

### 1.8 技术文档（Docs）与日志（Logs）
- 内置文档页（Markdown 渲染）；日志检索与清空。

## 二、配置说明

| 配置 | 位置 | 说明 |
|------|------|------|
| 鉴权开关 | .env AUTH_ENABLED | false 免登录（开发），true 走 JWT |
| AI 提供商 | .env 各 *_API_KEY | 多提供商故障切换 |
| 同步年数 | sync-full?years= | 默认 5 年 |
| 数据源 | eod-sync?source= | baostock / akshare |

## 三、常见问题排查

| 问题 | 可能原因 | 解决方案 |
|------|----------|----------|
| /health 返回 degraded | qlib 未同步 / DB 连接 / AI key 缺失 | 看 checks 明细逐项处理；先跑 sync-full |
| 同步返回 409 | 已有任务在跑 | 等完成或查 sync-progress |
| 评价/回测 503 | qlib 数据未就绪 | 先同步数据 |
| 校验报「长度异常」 | 日历增长未 pad | 跑 repair 或重新 eod-sync |
| baostock 请求超限 | 超 50k/日 | 隔日再跑，或改 akshare 源 |
| 启动被阻断 | production + 默认密钥 | 设强 SECRET_KEY/ADMIN_PASSWORD |
| 挖掘 429 | 限流 3/分钟 | 稍后再提交 |
| 日志找不到错误 | 级别过滤过严 | 调 config.yaml logging.level 或检索关键字 |
