# 因子挖掘指标清单

> 用途：因子挖掘/评价全流程可用的字段、算子与评估指标速查
> 数据源：baostock（qlib bin + PG）
> 最后更新：2026-08-03

---

## 一、基础特征字段（qlib bin）

当前回填写入的 8 个字段，因子表达式中以 `$field` 引用：

| 字段 | 含义 | 说明 |
|------|------|------|
| `$open` | 开盘价 | float32 |
| `$high` | 最高价 | float32 |
| `$low` | 最低价 | float32 |
| `$close` | 收盘价 | float32 |
| `$volume` | 成交量 | float32（股） |
| `$amount` | 成交额 | float32（元） |
| `$change` | 日涨跌幅 | 小数（如 0.025 = +2.5%） |
| `$tradable` | 可交易掩码 | 0/1（涨停跌停/ST 5% 限制） |

> 注意：**无** `$vwap`、`$adjclose`、`$factor`（复权因子）——baostock 不提供，不要在这些字段上构造因子。
> `$change` 与 `Ref($close,1)/$close - 1` 数值等价（均为小数涨跌幅）。

### PG 侧可扩展字段（暂未进 qlib bin）

`stock_daily` 表含全部 baostock 日线字段，若需要可作为因子输入扩展：
`preclose`、`turn`（换手率）、`tradestatus`、`pct_chg`、`is_st`、`pe_ttm`、`pb_mrq`、`ps_ttm`、`pcf_ncf_ttm`、`adjustflag`

## 二、表达式算子（qlib 语法）

### 时序算子（对单只股票时间轴）
| 算子 | 含义 | 示例 |
|------|------|------|
| `Ref(x, d)` | 滞后 d 天 | `Ref($close, 5)` |
| `Mean(x, n)` | n 日均值 | `Mean($close, 20)` |
| `Std(x, n)` | n 日标准差 | `Std($close, 20)` |
| `Delta(x, n)` | n 日差分 | `Delta($close, 5)` |
| `Slope(x, n)` | n 日线性回归斜率 | `Slope($close, 10)` |
| `WMA(x, n)` | n 日加权均线 | `WMA($close, 10)` |
| `EMA(x, n)` | n 日指数均线 | `EMA($close, 20)` |
| `Sum(x, n)` | n 日求和 | `Sum($volume, 5)` |
| `Max(x, n)` / `Min(x, n)` | n 日最大/最小 | `Max($high, 20)` |
| `Median(x, n)` | n 日中位数 | `Median($close, 10)` |
| `Quantile(x, n, q)` | n 日分位数 | `Quantile($close, 20, 0.8)` |

### 截面算子（每日对全市场）
| 算子 | 含义 | 示例 |
|------|------|------|
| `Rank(x)` | 当日截面排名（0~1） | `Rank($close)` |

### 关系/统计算子
| 算子 | 含义 | 示例 |
|------|------|------|
| `Corr(x, y, n)` | n 日滚动相关系数 | `Corr($close, $volume, 20)` |
| `Cov(x, y, n)` | n 日滚动协方差 | `Cov($close, $volume, 20)` |
| `Resi(x, y, n)` | 回归残差 | `Resi($close, $volume, 20)` |

### 条件与逻辑
`If(cond, a, b)`、`Greater(a,b)`、`Less(a,b)`、`Log(x)`、`Abs(x)`、`Sign(x)` 等基础函数。

> 表达式沙箱限制：禁止 `exec/eval/import`、拒绝负 `Ref`（未来数据）。

## 三、因子评价指标

### 3.1 核心指标（`compute_ic` 返回）
| 指标 | 字段名 | 含义 | 筛选用途 |
|------|--------|------|----------|
| IC | `ic` | Pearson 相关，因子值与未来收益的日截面相关均值 | 主筛选 |
| RankIC | `rank_ic` | Spearman 秩相关（alphalens 计算） | 对极端值稳健 |
| ICIR | `icir` | IC 均值/IC 标准差，衡量稳定性 | 高优先 |
| IR | `ir` | RankIC 均值/RankIC 标准差 | 辅助 |
| n_days | `n_days` | 有效样本天数 | 样本量检查 |

### 3.2 换手与衰减
| 指标 | 字段名 | 含义 |
|------|--------|------|
| 换手率 | `turnover` | TopK 持仓日更替比例（越低越稳定） |
| 衰减 | `decay` | IC 随滞后天数下降的斜率（越接近 0 越持久） |
| 换手曲线 | `turnover_curve` | 分组换手率分布 |

### 3.3 分层收益（alphalens）
- 分组净值曲线（quantile 1~5）
- 多空组合收益（long-short）
- 组间收益单调性（monotonicity）

### 3.4 统计验证（`factor_validator.py`）
| 指标 | 字段名 | 含义 |
|------|--------|------|
| 样本分割 | `sample_splits` | train/valid/test 三段（60/20/20） |
| 验证集 IC | `valid_ic` | 验证段 IC（**主筛选指标**） |
| 测试集 IC | `test_ic` | 测试段 IC（仅记录，不参与筛选） |
| 滚动统计 | `rolling_stats` | 滚动窗口 IC 均值/方差 |
| Newey-West t | `t_stat` / `p_value` | HAC 校正 t 检验（消除重叠标签自相关） |
| 显著性 | `significant` | p < 0.05 是否显著 |
| 稳定性 | `stability` | IC 信息比率（越高越稳定） |
| 正占比 | `positive_ratio` | IC > 0 的天数占比 |
| 多样性 | `is_duplicate` | 与已有因子 IC 序列相关度 > 0.8 视为重复 |
| 综合通过 | `passed` | 是否通过所有筛选 |

### 3.5 默认筛选阈值（config）
| 参数 | 默认值 | 含义 |
|------|--------|------|
| ic_threshold | 0.03 | IC 绝对阈值 |
| significance_alpha | 0.05 | 显著性水平 |
| stability_threshold | 0.5 | 稳定性（ICIR）阈值 |
| positive_ratio_threshold | 0.55 | IC>0 占比阈值 |
| decay_threshold | -0.01 | 衰减斜率阈值 |
| diversity_threshold | 0.8 | 重复相关度阈值 |
| eval_horizon | 5 | 标签前向收益天数 |

## 四、挖掘模板（5 个预设）

| 模板 | 关键词 | base_features | allowed_ops | 思路 |
|------|--------|---------------|-------------|------|
| momentum | 动量因子 | `$close $open $high $low $volume` | Ref/Mean/Std/Delta/Slope/WMA/EMA/Rank | 5-20 日动量 |
| volatility | 波动率因子 | `$close $high $low $volume` | Std/Max/Min/Corr/Cov/Ref/Mean/Rank | 10-60 日波动特征 |
| volume_price | 量价因子 | `$close $volume $high $low` | Corr/Cov/Sum/Rank/Ref/Mean/Std | 量价背离、放量信号 |
| reversal | 反转因子 | `$close $open $high $low` | Ref/Delta/Rank/Slope/Resi/Mean | 3-10 日短期反转 |
| sentiment | 情绪因子 | `$close $volume $high $low` | Sum/Mean/Std/Corr/Rank/Ref/Delta | 振幅/成交活跃度 |

## 五、可挖掘的因子类型速查

基于现有 8 字段 + 算子，理论上可构造：

- **动量类**：`$close/Ref($close, N) - 1`（N 日收益）、`Delta($close,N)/Ref($close,N)`
- **反转类**：`-Rank(Delta($close, 5))`、`Mean($close,5)/Mean($close,20) - 1`
- **波动率类**：`Std($close, 20)/Mean($close,20)`（变异系数）、`Max($high,20)-Min($low,20)`
- **量价类**：`Corr($close, $volume, 20)`、`Rank($amount)/Rank($volume)`、`$change * Rank($volume)`
- **趋势类**：`Slope($close, 10)`、`EMA($close,5)/EMA($close,20) - 1`（金叉）、`Mean($close,5)>Mean($close,20)`
- **振幅类**：`($high-$low)/$close`、`($high-$open)/$close - ($open-$low)/$close`（上下影线）
