# QLib 表达式学习

> 文档版本：v1.0 · 最后更新：2026-08-05
> 面向第一次写因子的用户，从零讲清"怎么写一个能被 QuantLab 接受的 QLib 因子表达式"。
> 本文所有字段与算子均来自平台实际白名单（`services/factor/expression.py`），
> 可在"因子库 → 新增因子"里直接保存验证。

---

## 一、表达式长什么样

因子表达式描述的是"用哪些数据、经过什么变换，得到每个交易日每只股票的一个数值"。
它由四部分组成：

| 组成 | 示例 | 说明 |
|------|------|------|
| 字段 | `$close` | 以 `$` 开头，引用日频数据列 |
| 算子 | `Mean($close, 20)` | 函数式调用，类似 `f(x, 参数)` |
| 运算符 | `+ - * /` | 普通四则运算，支持括号 |
| 常量 | `1`, `2.5`, `1e-12` | 数字字面量 |

最简单的表达式就是一个字段本身：

```text
$close
```

它不做任何加工。真正的因子一般是对字段做运算，例如"20 日动量"：

```text
$close / Ref($close, 20) - 1
```

含义：当前收盘价 除以 20 个交易日前收盘价 再减 1，得到 20 日涨幅。

## 二、字段：能引用哪些数据

平台把行情、宏观、财报、外盘数据都广播到了 qlib 数据层，表达式里用 `$` 开头引用。
**只能使用白名单内的字段**，写错字段名（或引用未同步的字段）会被沙箱拒绝。

### 2.1 日线行情（股票/指数都有的基础字段）

| 字段 | 含义 | 字段 | 含义 |
|------|------|------|------|
| `$open` | 开盘价 | `$high` | 最高价 |
| `$low` | 最低价 | `$close` | 收盘价 |
| `$preclose` | 昨收价 | `$volume` | 成交量（股） |
| `$amount` | 成交额 | `$turn` | 换手率 |
| `$tradestatus` | 交易状态 | `$pct_chg` | 涨跌幅（小数，如 0.03 = +3%） |
| `$is_st` | 是否 ST | `$adjustflag` | 复权标记 |
| `$change` | 日收益（复权正确） | `$tradable` | 可交易掩码（涨跌停/ST 5% 过滤） |

> 注意：价格按 **qfq 前复权** 存储，且 `$factor` 恒为 1.0。日收益请优先用 `$change`，
> 它基于除权后昨收计算，除权日不会产生虚假跳变。

## 三、运算符与常量

支持标准四则与比较运算符，可用括号调整优先级：

```text
$close * 1.01 > $open          # 收盘价比开盘涨超 1%
($high - $low) / $open         # 振幅
($close - $open) / ($high - $low + 1e-12)   # 带除零保护
```

**除零保护**：`$high - $low` 可能为 0（一字板），除零会产生 NaN/Inf。
惯例是在分母上加一个极小量 `+ 1e-12`，平台内置因子（如 Alpha158）都这么处理。

## 四、算子：函数式运算

算子采用函数调用语法：`算子名(参数1, 参数2, ...)`。参数可以是字段、常量，也可以是另一个算子调用（支持嵌套）。

### 4.1 时序算子（窗口回看，最常用）

这些算子按"每个股票自己过去 N 天"计算，N 是窗口大小：

| 算子 | 含义 | 示例 |
|------|------|------|
| `Ref(x, n)` | 取 n 个交易日前（n>0）或 n 天后（n<0）的值 | `Ref($close, 1)` = 昨日收盘 |
| `Mean(x, n)` | n 日均值 | `Mean($close, 20)` = 20 日均线 |
| `Std(x, n)` / `Var(x, n)` | n 日标准差 / 方差 | `Std($close, 20)` = 20 日波动 |
| `Sum(x, n)` | n 日求和 | `Sum($volume, 5)` = 5 日量能 |
| `Max(x, n)` / `Min(x, n)` | n 日最大 / 最小值 | `Max($high, 20)` = 20 日最高 |
| `Delta(x, n)` | 与 n 日前之差 | `Delta($close, 1)` = 当日-昨日 |
| `Slope(x, n)` | n 日线性回归斜率 | `Slope($close, 20)` |
| `Resi(x, n)` | n 日线性回归残差 | `Resi($close, 20)` |
| `WMA(x, n)` / `EMA(x, n)` / `MA(x, n)` | 加权 / 指数 / 简单均线 | `WMA($close, 10)` |
| `IdxMax(x, n)` / `IdxMin(x, n)` | n 日最大 / 最小值出现位置（距当前期数） | `IdxMax($high, 5)` |
| `Mad(x, n)` | n 日绝对偏差中位数 | `Mad($close, 20)` |
| `Count(x, n)` | n 日满足条件的次数 | `Count($close > Ref($close, 1), 20)` |

**注意 `Ref` 的方向**：`Ref(x, 20)` 是**20 天前**的值（过去）；`Ref(x, -1)` 是**明天**的值（未来）。
平台会**拒绝负数 Ref**——用未来数据构造因子是 look-ahead bias（前视偏差），回测结果会虚高。

### 4.2 截面算子（每天在全部股票之间比较）

| 算子 | 含义 | 示例 |
|------|------|------|
| `Rank(x, n)` | 窗口内截面排名 | `Rank($close, 20)` |
| `Quantile(x, n, q)` | 窗口内分位数 | `Quantile($close, 20, 0.8)` = 20 日 80% 分位 |

### 4.3 相关性算子

| 算子 | 含义 | 示例 |
|------|------|------|
| `Corr(x, y, n)` | n 日相关系数 | `Corr($close, Log($volume + 1), 20)` = 价量相关性 |
| `Cov(x, y, n)` | n 日协方差 | `Cov($close, $volume, 20)` |

### 4.4 数值变换

| 算子 | 含义 | 示例 |
|------|------|------|
| `Abs(x)` | 绝对值 | `Abs($close - Ref($close, 1))` |
| `Log(x)` | 自然对数 | `Log($volume + 1)` |
| `Sign(x)` | 符号（-1/0/1） | `Sign($pct_chg)` |
| `Power(x, y)` | 幂 | `Power($close, 2)` |
| `Clip(x, lo, hi)` | 截断到区间 | `Clip($pct_chg, -0.1, 0.1)` |
| `Floor(x)` / `Ceil(x)` | 向下 / 向上取整 | `Floor($close)` |
| `Skew(x, n)` / `Kurt(x, n)` | 偏度 / 峰度 | `Skew($close, 20)` |

### 4.5 比较与条件

| 算子 | 含义 | 示例 |
|------|------|------|
| `Greater(a, b)` / `Less(a, b)` | a>b / a<b | `Greater($close, $open)` |
| `Gt/Lt/Ge/Le/Eq/Ne` | >, <, ≥, ≤, =, ≠ | `Ge($close, Ref($close, 5))` |
| `If(cond, a, b)` | 条件选值 | `If($close > $open, $high, $low)` |
| `All(x, n)` / `Any(x, n)` | n 日全部 / 任一满足 | `All($close > Ref($close, 1), 5)` |

> qlib 比较运算的结果是 0/1（True=1, False=0），可参与算术，例如 `Mean($close > Ref($close, 1), 20)` 就是 20 日上涨概率。

## 五、从零组合一个因子

把上面的算子拼起来，就能构造经典因子：

```text
# 20 日动量（价格偏离 20 日前的幅度）
$close / Ref($close, 20) - 1

# 5 日反转（注意乘 -1）
-1 * ($close / Ref($close, 5) - 1)

# 20 日波动率（日收益标准差）
Std($close / Ref($close, 1) - 1, 20)

# 20 日上涨概率（类 RSI 强弱）
Mean(Greater($close / Ref($close, 1) - 1, 0), 20)

# 价格偏离 20 日均线
$close / Mean($close, 20) - 1

# 量比 5/20（近期放量程度）
Mean($volume, 5) / Mean($volume, 20)

# 20 日价量相关性（量价配合）
Corr($close, Log($volume + 1), 20)

# 20 日高点回撤（相对 20 日最高价的跌幅）
$close / Max($close, 20) - 1

# 复合：乖离率 + 量能确认（高阶写法，可嵌套）
If($close > Mean($close, 20), $volume / Mean($volume, 20), 0)
```

这些与平台"内置因子"（`services/factor/builtin_factors.py`）是一致的，可以直接在新增因子弹窗里试。

## 六、常见错误与规避

| 错误 | 后果 | 正确做法 |
|------|------|---------|
| `Ref($close, -5)` | 被沙箱**拒绝**（look-ahead） | 用正数 `Ref($close, 5)` 取过去 |
| 除零 `($high - $low) / ($high - $low)` | 全 NaN，IC 为空 | 分母加 `+ 1e-12` |
| 字段写错如 `$vwap` / `$volumn` | 被拒绝：不允许的字段 | 查本文 §2 白名单 |
| 算子写错如 `Rsquare` | 被拒绝：不允许的标识符 | 用白名单算子，或联系加白名单 |
| `Mean($close, 20) - 1` 缺少括号配对 | 语法错误 | 检查括号 |
| 表达式超过 2000 字符 / 嵌套超 20 层 | 被拒绝 | 拆分成多步或简化 |
| 直接在表达式里用 `import` / `open(` 等 | 被拒绝（安全沙箱） | 表达式只允许纯计算 |

### 6.1 为什么"负数 Ref"是严重问题

`Ref($close, -1)` 取的是**明天的收盘价**。如果用今天的因子预测明天收益，回测时因子值里混入了
明天才知道的价格，等于"开卷考试"，实盘不可能复现。因此平台在保存与执行两个环节都做拦截：
- 保存时：AST 沙箱检查 `Ref` 第二个参数必须是 ≥0 的常量
- 执行时：`load_factor_values` 还会再校验一次（防绕过）

> 唯一合法的"负数"用法是**标签**：评价 IC 时需要"未来 N 日收益"作为预测目标，
> 那是平台内部用 `forward_return_label` 构造的（基于 `Ref($change, -N)`），用户表达式里不允许。

## 七、校验规则速查（安全沙箱）

保存新因子时，平台会对表达式做以下检查（任一不过即拒绝并给出原因）：

- 长度 ≤ 2000 字符
- 字段必须属于白名单（§2）
- 函数名必须属于算子白名单（§4）
- 无 `import`/`exec`/`eval`/`open(`/属性访问等危险结构
- 无 `__`、`compile`、`builtins` 等危险子串
- AST 节点数 ≤ 1000，嵌套深度 ≤ 20
- `Ref` 不允许负数参数
